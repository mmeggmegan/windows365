# Previews in Windows 365

Windows 365 releases some features in preview prior to general availability (GA). Generally, these are features that have new customer-facing functionality and would benefit from being tested in a range of external use cases, workloads, and environments. These features are being actively developed and may not be complete. 

Windows 365 previews are subject to your organization’s agreement with Microsoft, including the preview terms found in the Universal License Terms for Online Services and the Microsoft Product and Services Data Protection Addendum. Learn more at:  https://www.microsoft.com/licensing/terms/product/ForOnlineServices/MCA.

## Private previews

A private preview is a limited external pre-release validation of a feature that has:
•	Restricted access offered for a limited time and potentially has limited functionality.
•	No public comms and support is provided by the product team.
•	A likelihood of feature changes prior to GA.

Accessing a private preview
Private previews are offered through the Microsoft Management Customer Connection Program (Management MCCP). This confidential program provides opportunities for IT Pros and Microsoft engineering teams to work together developing solutions that better address commercial customer needs and result in product improvement. Request membership at aka.ms/JoinCommunity.

Private preview capacity is often limited based on the scope of the feature as well as the capacity of the product team. Preference is given to customers that have previously indicated that the lack of this feature is a high priority blocker for their organization. Work with your Microsoft representative to have this information logged. 


## Public previews

A public preview is a publicly announced external validation of a feature that has:
•	Individual features in preview may have usage, functionality, and support limitations. If so, this information is typically noted in the feature documentation.
•	A likelihood of feature changes prior to GA.
•	Are supported by Microsoft.

Accessing a public preview feature:
Public preview features have a (preview) tag in the admin user interface (Microsoft Intune admin center, Microsoft 365 admin center, and windows365.microsoft.com). You can test and use these features in production environments and scenarios. Customers that see those tags can access the public preview feature and do not need to sign-up or request access, unless otherwise noted.
